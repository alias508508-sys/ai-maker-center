# AI创新每日top排行榜

正式首页展示独立的每日榜单：电脑端每行4篇、共2行、最多8篇；平板2列、手机1列。下方全部资讯的分类、搜索与More加载保持原有行为。

入选必须有已经保存至服务器的真实缩略图，不使用替代封面。四个分类统一竞争，不另设教育榜。创新性35%、AI相关性30%、实践价值20%、启发与教育价值10%、证据与可信度5%；各维度0–5分。AI相关性及创新性均需至少3分，总分至少70分。70分为站主同意的首版试用门槛，需随实际内容校准。排除纯广告、无实质内容、低AI相关性及重复事件；不足8篇不凑数。

评分材料为通过公开读取层导出的当前公开资讯标题、摘要与来源，不冒充对全文或项目真实性的独立验证。调用部署的默认模型（目前为DeepSeek），通过原有付费回执与预算限制，不在浏览时调用。按内容哈希缓存评价，只有新增或内容改变时再次付费评估。公开的历史每日文件仅包含已公开资讯与推荐分数、推荐理由，不包含密钥、回执或原始模型响应。

服务器任务 `/usr/local/sbin/maker-rankings` 使用共享采集锁，执行 `scripts/maker-rankings.ts` 后生成正式首页。定时器 `maker-rankings.timer` 每天北京时间08:30运行，历史结果保存在 `pages-preview/rankings/YYYY-MM-DD.json`，当前期在 `latest.json`。历史内容属于公开导出快照，未重复存入另一套数据库。首次发布会评估当前所有有图资讯，之后每期仅在自上一期以来新发现的有图内容中选取（按北京时间首次发现日期记入本期），同日重跑保留本期候选。分数缓存按内容哈希复用，旧内容不会长期霸占每日榜单。

生成失败时保留前一期和现有首页，原始分数缓存留在私有 `.data/maker-ranking-scores.json` 以便续跑。普通资讯允许无图，只是榜单禁止无图；若图片文件后来删除，下一次生成首页时剔除该条。排名相同时按创新性、实践价值、证据分依次比较。

验证：`node --test scripts/maker-ranking-rules.test.ts` 覆盖无图、广告、低相关性、低创新、重复事件、非公开URL、8篇上限和不足不凑数；浏览器核验正式站的8图加载、4列2行及移动端无横向溢出。
