# 管理员密码

登录后台，在 `/admin/settings` 的“修改管理员密码”中填写当前密码、新密码和确认新密码。新密码为 12 至 256 位。保存后所有密码会话失效，使用新密码重新登录；飞书会话不受影响。

首次登录仍使用 `ADMIN_PASSWORD`。修改后，数据库 `admin_password` 保存随机盐的 scrypt 哈希，覆盖环境中的初始密码；重启不会恢复旧密码。审计只记录修改事件，不记录密码或哈希。数据库备份包含此哈希。

恢复：只有服务器维护者在确认管理员身份后，才可清空 `admin_password` 单行记录并清除密码会话，恢复环境中的初始密码。不要把密码写入 Git 或聊天。
