# RSS订阅

当前正式站通过原框架的公开读取层提供最近50条公开资讯摘要，不在阅读时调用AI。

- `/feed/all.xml`：全部公开动态 RSS，供阅读器订阅。
- `/feed.xml`：指向同一全部动态源，兼容常见默认地址。
- `/subscribe.html`：订阅说明和复制订阅地址。
- 首页包含标准 `rel=alternate` RSS自动发现标签，阅读器添加首页网址即可发现订阅源。

NGINX把这些订阅和文章阅读路径转给原应用：`/feed/`、`/items/`、`/all`、`/api/img-proxy`。订阅仍遵循原框架的公开范围、摘要与版权限制，不包含后台资料。GUID由原应用的文章ID稳定生成，原标题摘要更新不造成重新订阅；原来源发布时间仍由原实现提供。

更新提醒由RSS阅读器的检查频率、阅读器通知设置和操作系统通知权限决定，网站本身不发送手机推送或邮件。现阶段使用服务器IP；域名HTTPS接通后，订阅页会自动使用当前域名生成地址。

上线验证：公开RSS返回200及application/rss+xml，XML可解析，50个条目GUID各不相同，文章阅读页正常返回200。首页自动发现标签、移动端布局和复制按钮用浏览器检查。
